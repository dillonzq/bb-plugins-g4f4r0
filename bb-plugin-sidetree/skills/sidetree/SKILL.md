# Sidetree

The user has a **Files** tab in the thread's right panel (New tab → Files).
It lists the current thread environment. Clicking a file opens it in BB.
Do not send the user to an external editor.

Do not run a Sidetree CLI. Read and edit workspace files with your normal
file tools. Point the user at **+ → Files** if they are looking for the tree.
