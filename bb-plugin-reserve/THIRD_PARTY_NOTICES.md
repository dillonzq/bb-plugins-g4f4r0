# Third-party notices

Reserve adapts usage normalization, Codex reset-credit RPC, and the reset
confirmation gate from Usage Tracker by Mateo Cerquetella (MIT):

https://github.com/MateoCerquetella/bb-plugins/tree/main/plugins/usage-tracker

See `licenses/USAGE-TRACKER-MIT.txt`.

Grok has a scheduled weekly pool reset. It does not expose a Codex-style
banked consume API, so Reserve shows the next reset time and does not offer
a Grok consume button.
