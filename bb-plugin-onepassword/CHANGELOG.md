# Changelog

## 0.1.0-alpha.1

Initial development preview: BB dashboard, native agent tools and CLI; separate passkey approval service; encrypted service account storage; restricted field/Environment mappings; profile fingerprints; protected command and browser workers; revocation, expiry, audit history, and deployment/security/privacy documentation.

Real-account/device validation and independent security review are required before public release.

Added a disposable, credential-free demo for trying a real passkey saved in 1Password without configuring production vault access. Shopify requests in this demo are explicitly simulated.
